# موقع تعلّم اللغة الإنجليزية

موقع يفتح للمستخدم درسًا جديدًا كل يوم، مع حسابات للمستخدمين ولوحة تحكم لإدارة الدروس.
لا يحتاج إلى تثبيت أي مكتبات؛ يكفي Node.js بإصدار 18 أو أحدث.

## التشغيل محليًا
    ADMIN_PASSWORD="كلمة-مرور-قوية" node server.js
ثم افتح http://localhost:3000 للموقع، وhttp://localhost:3000/admin للوحة التحكم.

## متغيرات البيئة (على الاستضافة)
| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم (إلزامية لتفعيل `/admin`). |
| `SECRET` | سلسلة عشوائية طويلة لتوقيع الجلسات. يجب أن تبقى ثابتة. |
| `TRUST_PROXY=1` | عند وجود وسيط (Render وNginx وغيرهما) ليُقرأ عنوان الزائر الحقيقي. |
| `STORAGE_DIR` | مسار القرص الدائم (مثل `/var/data`). تُحفظ فيه الحسابات والدروس. |
| `PORT` | المنفذ (الافتراضي 3000). |

## الإعدادات
ملف `config.json`: اسم الموقع والنصوص والمنطقة الزمنية ونمط الجدولة:
- `visitor`: يبدأ كل مستخدم من الدرس الأول يوم تسجيله، ويُفتح له درس جديد كل يوم.
- `calendar`: يبدأ الموقع كله في `startDate`، ويرى الجميع الدرس نفسه في اليوم نفسه.

## إدارة الدروس
من `/admin` يمكنك إضافة الدروس وتعديلها وحذفها وإعادة ترتيبها ومعاينتها.
ترتيب الدروس هو ترتيب أيام الفتح. كل درس يُحفظ ملف JSON في مجلد `lessons/`.

## التخزين الدائم (مهم)
يُحفظ الحسابات في `data/users.json` والدروس في `lessons/`.
اربط قرصًا دائمًا (Persistent Disk) بالخادم واضبط `STORAGE_DIR` على مساره؛
عندها تُنسخ الدروس المرفقة مرة واحدة عند أول تشغيل، ولا تُمسح تعديلاتك عند إعادة النشر.
بدون قرص دائم قد تُمسح الحسابات والدروس عند إعادة التشغيل.

## الحماية
- كلمات المرور مشفّرة بخوارزمية scrypt مع ملح خاص بكل مستخدم.
- الجلسات في كوكيز موقّعة (HttpOnly وSameSite).
- لا تُرسل الدروس إلا لمستخدم مسجّل وفي يومها، وتبقى إجابات الاختبارات في الخادم.
- حدّ لعدد المحاولات على الدخول، وفحص لمصدر الطلبات، وترويسات أمان (CSP وغيرها).
- لا يوجد تحقق من البريد الإلكتروني ولا استعادة لكلمة المرور (يتطلب خدمة بريد). يمكن للمدير حذف الحساب من لوحة التحكم ليعيد المستخدم التسجيل.
